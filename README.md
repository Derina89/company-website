# Company Website — Task 1

## Project Overview

This project is a responsive company website developed as part of the SAN Web Technology Full-Stack Development Internship.

The website provides a simple and user-friendly interface with dedicated Home, About, and Contact pages. It is designed to work across different screen sizes and provides easy navigation between its pages.

## Features

- Home page with company information
- About page describing the company
- Contact page with contact information and a form
- Navigation between pages
- Responsive design for desktop and mobile devices
- User-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

The project contains the website's HTML pages, stylesheets, JavaScript files, and related assets.

## How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open the `index.html` file in a web browser.

No backend server is required.
